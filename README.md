# テザリング自動

車のBluetooth(カーナビ・ヘッドユニット)に接続したらテザリングをON、切断したらOFFにするAndroidアプリです。**ロック画面・画面オフの状態でも動きます。**

**Languages / 言語:** 日本語 · English · 简体中文 · 한국어(端末の言語に自動で合わせます)

## しくみ
Bluetoothの接続を検知 → 画面を点灯 → クイック設定パネルを開く → テザリングのタイルを文字で探して押す → 状態を確認 → パネルを閉じて元の状態に戻す、をアクセシビリティサービスで自動実行します。

## インストール
1. [最新版のAPK(TetherAuto-latest.apk)](https://github.com/ino-tools/tether-auto-public/raw/main/TetherAuto-latest.apk)をダウンロードして開き、インストールします(「提供元不明のアプリ」の許可が必要です)。
2. アプリを開き、「はじめの設定」の順に進めます。
   - 制限付き設定を許可(Android 13以降で、アクセシビリティをONにできないとき)
   - アクセシビリティをON
   - Bluetoothの権限を許可
   - 電池の最適化を外す
3. 「連動するBluetooth機器」で車載機器を選び、「ON」「OFF」ボタンでテストします。

## 対応機種について
タイルの名前(Hotspot / テザリング / 热点 / 핫스팟 など)を内蔵の一覧から探します。見つからないときは、アプリの「詳細設定」で名前を入力してください。実機で確認できているのは下の環境だけです。

## 動作確認済みの環境
- Xperia 1 VIII / Android 16(日本語表示)

他の機種では、タイルの名前が違うことがあります。アプリの「詳細設定」でタイルの文字を変えてください。動かないときは、アプリの「意見箱」から機種名つきで教えてください。

## 安全性の確認
- **ウイルス検査**: [VirusTotalの検査結果](https://www.virustotal.com/gui/file/3fec6b9c2d01248b2e9a351fe72eb5a340a10592056ffeaa66604a342053caa9)(v1.3.1。検査できるすべてのエンジンで「検出なし」でした)。
- **付けている権限は3つだけ**です: アクセシビリティ(クイック設定の操作用)、Bluetooth接続の確認、画面を起こす権限(WAKE_LOCK)。
- **インターネット権限は付けていません**。そのため、端末の外へデータを送ることはできない作りです。
- **ファイルの確認**: v1.3.1 の SHA-256 は `3fec6b9c2d01248b2e9a351fe72eb5a340a10592056ffeaa66604a342053caa9` です。ダウンロードしたファイルと一致するか確認できます。
- アクセシビリティ権限を使うアプリなので、不安な場合は無理に入れないでください。

## プライバシー
このアプリは通信を行わず、個人情報を収集しません。アクセシビリティの権限は、クイック設定パネルの操作だけに使います。ログは端末内にのみ保存されます(意見箱で「ログを添付」を選んだときだけ、機器のアドレスを伏せて送信内容に含まれます)。
